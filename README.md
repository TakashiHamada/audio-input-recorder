# 🎧 ライン入力レコーダー (Game Audio Recorder)

Macのオーディオ入力端子につないだ**ゲームの音声を、ロスレス(WAV)でキレイに録音**するためのWebアプリです。
インストール不要・ブラウザだけで動作し、音声は一切外部に送信されません(すべて端末内で処理)。

## できること

- 入力デバイスの選択(USBオーディオI/F・ライン入力など)
- **音声通話向けの加工をオフ** — ノイズ抑制 / エコーキャンセル / 自動ゲインを無効化し、ゲーム音をそのまま録音
- ステレオ / モノラル、16-bit / 24-bit の選択
- L/R レベルメーター + クリップ(歪み)警告
- 入力ゲイン調整(±24 dB)
- 入力モニター(ヘッドホンで確認)
- **WAV(ロスレス)で保存** — その場で再生・ダウンロード

## 使い方

1. ゲーム機のオーディオ出力を、ケーブルでMacの**ライン入力**につなぐ。
   - ⚠️ 多くのMacBookの3.5mm端子は**出力専用**です。入力がない場合はUSBオーディオインターフェイスや「ライン入力対応」のUSBアダプタを使ってください。
   - システム設定 → サウンド → 入力 で、デバイスが認識されレベルが振れることを確認。
2. このアプリを開き、「マイク／入力を許可」をクリック。
3. 入力デバイスを選択(音質設定は初期状態のまま=加工オフが推奨)。
4. レベルメーターを見ながらゲームを鳴らし、メーターが赤の上端に張り付かない音量に調整。
5. 「録音開始」→ 終わったら「録音停止」→ ダウンロード。

> ブラウザの仕様上、マイク/入力へのアクセスには **HTTPS** が必要です。GitHub Pages はHTTPSなのでそのまま動作します。

## GitHub Pages で公開する

このアプリは静的ファイルのみなので、ブランチをそのまま Pages で配信できます。

1. GitHub のリポジトリ → **Settings → Pages** を開く。
2. **Build and deployment → Source** を **Deploy from a branch** にする。
3. 公開したいブランチ(例: `main`)と `/ (root)` を選んで保存。
4. 数十秒後、`https://<ユーザー名>.github.io/audio-input-recorder/` で公開されます。

## ローカルで確認する

リポジトリ直下で簡易サーバーを起動してください
(`file://` ではマイク権限とAudioWorkletが動きません):

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 対応ブラウザ

`getUserMedia` と `AudioWorklet` に対応した最新のブラウザ(Chrome / Edge / Safari / Firefox)。macOS の Safari / Chrome で動作します。

## プライバシー

録音した音声はサーバーへ送信されず、ブラウザ内でのみ処理されます。ダウンロードしたファイルはお使いの端末に保存されます。
